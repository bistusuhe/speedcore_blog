文字内容来源：

- config/site.ts + .env — 网站标题、作者名、GitHub 链接
- i18n/messages/zh.json — 所有中文 UI 文案（导航、Hero、关于我、按钮标签等）
- i18n/messages/en.json — 对应的英文翻译
- config/experiences.ts — 实习经历、获奖荣誉、兴趣爱好
- content/posts/*.mdx — 博客文章
- content/projects/*.mdx — 项目展示
- .env — 邮箱、微信二维码等敏感/可变信息

一句话：数据改 config/，文案改 i18n/，秘密改 .env，文章改 content/。

博客图片用法：

- 图片统一放在 public/images/posts/postsimage/ 目录中
- MDX 文章里引用时不要写 public，路径从 /images 开始
- PNG 示例：![图片说明](/images/posts/postsimage/example.png)
- JPG 示例：![图片说明](/images/posts/postsimage/example.jpg)
- 文章封面在 Frontmatter 中填写：cover: '/images/posts/postsimage/example.jpg'
- 请将 example.png 或 example.jpg 替换成图片的实际文件名
- 建议图片文件名使用英文小写、数字和连字符，避免空格
- 图片放入目录后需要和文章一起提交到 Git

h1-h6 标题：# 到 ######，自动生成锚点 id + hover 可见链接锚点，不同级别有不同字号间距

Callout 提示框：自定义组件，需在文章顶部 import Callout from '@/components/blog/callout'，然后用 <Callout type="info" title="标题">内容</Callout>，type 可选 info / tip / warning / danger，title 可选

Mermaid 图表：import Mermaid from '@/components/blog/mermaid'，然后用 <Mermaid chart={图定义} />

数学公式：$inline$ 行内，$$block$$ 块级，KaTeX 渲染
