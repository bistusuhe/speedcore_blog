## 关于游戏

**Observer｜你在吗？** 是一款使用 Godot 4 制作的横向像素叙事探索游戏。你会在不同场景中行走、跳跃，与人物交谈，调查环境中的细节，并将收集到的线索用于解开轻量谜题。

这是一个可以从开头游玩到结尾的版本。故事适合自己慢慢发现，这里只介绍玩法，不展开剧情。

## 你会体验到

- 横向像素场景中的探索与平台跳跃
- 与人物对话、调查环境、整理线索手册
- 穿插在旅程中的轻量谜题与提示
- 自动存档、章节选择与进度继续

## 操作方式

| 操作 | 按键 |
| --- | --- |
| 移动 | A / D 或 ← / → |
| 跳跃 | Space、W 或 ↑ |
| 奔跑 | Shift |
| 对话 / 调查 | E |
| 线索手册 | Tab |
| 暂停 / 返回 | Esc |

菜单和谜题也可以使用鼠标操作。游戏无需账号或网络。
